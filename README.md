# Machine Learning Projects

## Overview
This repository contains a collection of machine learning projects developed using Python and scikit-learn as part of academic and practical coursework.

The projects cover multiple areas of machine learning, including:
- Data preprocessing
- Feature extraction
- Classification
- Clustering
- Dimensionality reduction
- Model evaluation and optimization

These projects demonstrate the implementation of machine learning workflows on real-world and synthetic datasets using different algorithms and evaluation techniques.

## Projects

### 1. Data Preprocessing and Feature Extraction
Focuses on image preprocessing and feature extraction using SIFT descriptors and landmark datasets.

#### Topics Covered
- Image preprocessing
- SIFT feature extraction
- Dataset preparation
- Data representation for machine learning tasks

#### Technologies
- Python
- OpenCV
- NumPy
- Pandas

---

### 2. Spotify & YouTube Classification
Machine learning project focused on classifying tracks using Spotify and YouTube metadata and audio-related features.

#### Topics Covered
- Data cleaning and preprocessing
- Exploratory data analysis
- Classification models
- Feature selection
- Model evaluation using F1-score and accuracy metrics

#### Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

---

### 3. Advanced ML Models

#### Topics Covered
